Illustration options · same housing society, four styles

Choose how the drawings should look

Every option is built from one shared scene description, so any of them can show all four property types. Use Replay to see each style animate. Option D is a real 3D scene you can drag. Everything is illustrative, not to scale.

A · Polished isometric

SVG only0 KB extraBest all-rounder
  • Today's style, upgraded: gradient shading, ground shadows, windows, rooftop tanks.
  • Sharp on every screen, prints well, loads instantly, easy to restyle.
  • Limit: fixed viewpoint, so no rotating.

B · Blueprint line art

SVG only0 KB extraMost "technical"
  • White lines on navy with a drafting grid, hatched coverage, drawn on with GSAP DrawSVG.
  • Feels like a real security plan. Works well on dark sections like the process band.
  • Limit: less friendly for homeowners; harder to show zone colours.

C · Soft clay

SVG only0 KB extraFriendliest
  • Rounded, matte, soft shadows. Reads as modern and approachable.
  • Good for home and shop audiences. Windows hidden for a calmer look.
  • Limit: less precise, so it suits marketing more than planning detail.
3D loads when this scrolls into view

D · Real 3D (Three.js)

~150 to 180 KB gzip (approx.)Lazy-loadedMost impressive
  • Drag to rotate. Cameras sweep with real field-of-view cones. Soft shadows.
  • Best loaded on demand ("Explore in 3D") so first paint stays fast.
  • Limit: bigger download, more work per property type, needs a static fallback.

My recommendation

  • Default style: A. It keeps the site fast and matches your Blueprint direction. Use B inside the dark process band so the page has one technical moment.
  • Add D as an optional "Explore in 3D" button on the planning section only. It loads on click, so visitors who do not want it pay nothing.
  • Add Lucide, Embla and shadcn/ui now, and drop anime.js in favour of GSAP to get the motion bundle under budget.
  • C is lovely but better kept for a future residential-only landing page.
