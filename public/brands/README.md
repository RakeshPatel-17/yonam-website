# Brand logos

Drop the official logo files here. The site uses a file when it exists and shows the brand name as text when it does not.

| Brand | File name (svg, png or webp) |
|---|---|
| CP PLUS | `cp-plus` |
| Honeywell | `honeywell` |
| Prama India | `prama` |
| Dahua | `dahua` |

Rules
- Use the files supplied by each brand or its distributor (dealer or partner portal, brand kit). Brand logos are registered trademarks. Dahua, for example, requires written permission for co-logoing, so confirm each brand's terms before publishing.
- Prefer SVG. For PNG use at least 2x the display height (64 px tall or more) with a transparent background.
- Keep the logo unmodified (no recolouring or stretching). The page shows it in greyscale and restores colour on hover with CSS only.
- Add the file name to the commit message so the permission trail is clear.
